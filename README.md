# Healthcare Quality Automation & Feedback System

### Lean Six Sigma Yellow Belt | Process Improvement | Excel/VBA | Quickbase

## Project Overview

This project focused on improving a healthcare quality audit and feedback process used to evaluate production transactions and identify errors before they could be identified through downstream client-side audits.

The existing process relied heavily on individual Excel files, manual data consolidation, manual scoring, manual feedback communication, and report preparation. These activities created opportunities for missed feedback, data-entry errors, duplicate audits, reporting delays, and limited real-time visibility.

The improvement journey began with an Excel/VBA-based automation concept and was subsequently transformed into a centralized Quickbase solution.

---

## Business Problem

The existing audit process involved multiple manual activities across the audit lifecycle.

Key challenges included:

* Individual Excel files maintained by QAs
* Manual consolidation of audit data
* Manual audit scoring
* Manual preparation of feedback emails
* Risk of incorrect Case IDs, Agent IDs, names, dates, and other details in feedback
* Missed feedback communication
* Duplicate case audits
* Manual error categorization and trend tracking
* Time-consuming report preparation
* Limited real-time visibility for team leads and operations
* Dependency on multiple files and copy-paste activities

The baseline average audit time was **42.50 minutes per audit**.

---

## Project Objective

The objective was to improve the efficiency, accuracy, visibility, and scalability of the quality audit and feedback process by reducing manual activities and introducing automation.

The project aimed to:

* Reduce audit turnaround time
* Improve audit-data accuracy
* Prevent duplicate audits
* Automate audit scoring
* Improve feedback accuracy and timeliness
* Establish feedback tracking
* Centralize audit information
* Improve error-trend visibility
* Reduce manual reporting effort
* Enable real-time access to audit information

---

## Lean Six Sigma Approach

The project applied selected Lean Six Sigma tools based on the nature of the improvement initiative.

### SIPOC

SIPOC was used to understand the end-to-end process and identify the key suppliers, inputs, process activities, outputs, and customers.

**Suppliers:**
QCA Team, Process Owners, Internal Systems

**Inputs:**
Audit Parameters, Error Logs, QA Guidelines, Scoring Criteria

**Process:**
Collect Audit Data → Evaluate Transactions → Identify & Analyze Errors → Calculate Audit Scores → Provide Individual Feedback → Generate Performance Reports

**Outputs:**
Automated Audit Scores, Error Trend Reports, Individual QA Feedback, Consolidated Performance Dashboards

**Customers:**
QCA Team, Team Leads, Operations Team, Agents

### FMEA

FMEA was used to identify potential failure modes within the audit and feedback process and prioritize opportunities for improvement.

Key risk areas included:

* Manual data entry
* Duplicate case audits
* Incorrect feedback information
* Missed feedback
* Manual error categorization
* Reporting inaccuracies
* Delayed consolidation
* Limited real-time visibility

The identified risks were subsequently addressed through process automation and centralization.

---

## Improvement Journey

The solution evolved through two major stages.

### Stage 1 — Excel/VBA Automation

Before moving to a centralized platform, an Excel/VBA-based solution was developed to address immediate manual pain points.

The solution:

* Maintained audit records in a personal audit-tracking workbook
* Used VBA/VLOOKUP-based automation to retrieve relevant agent and case information
* Reflected audit scores into the required audit record
* Generated the required feedback email template through VBA
* Reduced repetitive data entry and copy-paste activities

This initial solution demonstrated the potential for automation while also highlighting the limitations of maintaining a process across multiple individual Excel files.

### Stage 2 — Quickbase Automation

The improvement was subsequently migrated to a centralized Quickbase solution.

The centralized system provided:

* Bulk case upload
* Centralized audit records
* Duplicate case prevention
* Automated agent-information retrieval from the roster
* Structured error capture
* Automated audit-score calculation
* Automated feedback email triggering
* Feedback tracking
* Error-trend dashboards
* Filterable reporting
* Consolidated performance dashboards
* Real-time visibility
* Reduced dependency on multiple Excel files

## Key Takeaways

This project demonstrated how a process improvement initiative can evolve from a simple automation concept into a centralized workflow solution.

The improvement was not limited to reducing audit time. It addressed multiple process risks by combining:

**Process Analysis + FMEA + Excel/VBA Automation + Quickbase + Standardization + User Adoption**

The project resulted in improved audit efficiency, increased audit capacity, automated feedback, improved data accuracy, centralized reporting, and enhanced process visibility.
